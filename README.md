# cyberhunt_ipsita
OVERVIEW

Engineered a fully automated background data pipeline on Make.com that handles end-to-end data ingestion, sanitization, and live reporting.

TECHNICAL ARCHITECTURE BREAKDOWN 

Ingestion: Automatically monitors and parses live RSS data streams on a structured cron schedule.

Algorithmic Filtering: Implements strict data normalization to extract geo-location markers and isolate specific target properties.

Stealth Intelligence: Routes automated HTTP web-scraping queries through a public CORS proxy wrapper to dynamically audit and flag organizational ratings.

Defensive Gateway: Employs case-insensitive text operators to filter out low-tier or fraudulent profiles before data distribution.

Database & Notification: Synergizes with the Google Sheets API for persistent storage while simultaneously dispatching instant alerts via Gmail.
