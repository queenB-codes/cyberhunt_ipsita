CyberHunt Engine

Automated Threat & Job Intelligence Pipeline

Engineered a fully automated background data pipeline on Make.com that handles end-to-end data ingestion, sanitization, and live reporting. Monitors RSS threat feeds in real-time, normalises geo-location markers, routes HTTP scraping through CORS proxy wrappers, and dispatches instant Gmail alerts — all running on a structured cron schedule. Integrates Google Sheets API for persistent storage and live dashboard reporting.
